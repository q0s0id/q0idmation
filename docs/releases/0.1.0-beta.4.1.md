# q0idmation v0.1.0-beta.4.1

this is a substantial update to beta.4: expanded fla compatibility, scene and library organization, timeline improvements, edit mode in place, performance work, and the polish overhaul.

## polish overhaul

- shared vector icons replace many text buttons across the timeline, document tabs, library, scene controls, and rig controls. the icons do not depend on special font glyphs; hover hints explain their actions.
- menu shortcuts and tool hints show the user's actual configured bindings.
- the layer-name column can be resized, reduced to an icon-focused view, and reset by double-clicking its divider. its width is saved between launches.
- long scene, layer, tab, and replacement-card names use the available space and show their full names in tooltips.
- clearer active tabs, unsaved-change indicators, drag handles, and compact playback controls.
- search fields have a clear button and escape handling. rename controls accept enter, cancel with escape, and reject blank names.
- frame picker and replacement cards share their appearance and adaptive preview backgrounds.
- clicking a breadcrumb inside nested symbols now returns to the selected level and restores the parent frame.
- removed placeholder characters from effect and rig controls and clarified several tool hints.

## scenes, library, and symbol workflows

- scene switching and renaming in a compact list in project properties.
- library folders, including imported animate library folders; replacement previews are grouped by folder.
- `Replace q0rg` is available from the stage context menu and instance properties. replacements belong to the current keyframe, create a keyframe when needed, and carry forward into later keyframes.
- replacement fitting keeps proportions while preserving the previous instance's visual scale as closely as the artwork bounds allow.
- the replacement window opens at the current symbol, highlights it, and opens its folder.
- `Spread between layers` and `Spread between keyframes` distribute selected objects in their depth order through the context menu.
- cross-project copy and paste carries the required symbol/asset dependencies and preserves object stacking order. ordinary object paste uses the destination layer.
- quick horizontal and vertical flips, alt-drag duplication, and `Copy Symbol` in the context menu.
- library selection supports shift and ctrl workflows; project tabs can be reordered.
- selecting a stage object follows its layer in the timeline; shift selection toggles only the clicked object. inserting a keyframe keeps the selected objects.
- edit mode in place keeps the parent artwork visible around the symbol being edited, using the instance's transform.
- project creation remembers custom dimensions, fps, and frame count; keyboard shortcuts can be customized and reset.

## timeline and masks

- layers can have independent timeline lengths. removing selected frames shortens and shifts only the affected layers, including empty spans; cells after that layer's end are beyond cells.
- `Shift+F5` and the frame context menu use the layer-local removal action. deleting complete time columns remains a separate operation.
- `F5` inserts hold frames on selected layers. selecting beyond cells can extend several layers with `F5` or `F6`.
- distant keyframes do not shift existing keys. extending a timeline by one keyframe can extend layers that ended at the same point, while shorter layers stay shorter.
- frame and layer context menus show actions appropriate to the clicked area.
- ctrl-click frame selection, multiple-layer movement, lock-all layers, timeline hiding, and layer-specific outline controls.
- onion skin follows the active layer.
- mask layers have their own icon, collapsible contents, group visibility, and a separate artwork/preview control.
- while mask artwork is visible, its contents stay visible without clipping for editing. hiding the artwork previews the clipped result. the artwork control uses a stencil icon distinct from the normal eye.
- nested symbols, library previews, and exports retain the composited mask result. supported masks use the vector/gpu path; unsupported combinations use the software fallback.

## fla/xfl import and file compatibility

- xfl-based fla import now carries vector artwork, symbol instances, text, media, scenes, folders, playback settings, camera information, and timeline masks, with diagnostics for unsupported content.
- imported groups are converted into q0rg symbols so their nesting and transforms are retained.
- import corrections cover folder ordering, out-of-range playback frames, zero text sizes, invalid filter values, and degenerate gradient transforms.
- text positioning and camera/background handling have been improved.
- legacy binary fla containers now have an initial recovery path. this is partial support: recoverable vectors are imported as static artwork; legacy timeline animation, symbol placements, text, and bitmap media are not mapped yet.
- multiline on-canvas text entry, transformed text editing, and deselection by clicking outside the text box.
- canonical project save/parse-back fixes and updated format readers in q0player.
- current file versions are **q1s v32** and **q0s v31**. update both q0editor and q0player; older builds may reject files written with the new fields.

## performance and canvas correctness

- reduced repeated scene traversal, geometry construction, bounding-box work, and off-screen library work on large projects.
- more targeted render-cache invalidation after edits, including eraser operations, and reduced clipboard dependency snapshots.
- fixes for stale artwork after dragging: rendered objects, selection bounds, and transform anchors are synchronized.
- performance snapshots remain available through `F4` or its configured replacement.
- these changes target expensive editor paths; performance still depends on the project's visible content and effects.
